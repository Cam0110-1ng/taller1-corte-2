## 🎯 ¿Qué es este Proyecto?

Este repositorio es un **proyecto académico** que corresponde al primer taller del segundo período de evaluación de un curso universitario. Su propósito principal es:

1. **Aplicar conocimientos teóricos** en un proyecto práctico
2. **Desarrollar habilidades** de programación y desarrollo de software
3. **Demostrar competencias** en el uso de herramientas profesionales
4. **Crear un portafolio** de trabajo académico

## 📚 ¿Por qué existe este Proyecto?

En el contexto educativo:

- Los **cortes** son períodos de evaluación académica (generalmente 3 por semestre)
- Los **talleres** son actividades prácticas para aplicar conocimientos
- Este es el **primer taller del segundo corte**, una evaluación importante

El proyecto sirve para:
- Evaluar el progreso del estudiante
- Aplicar conceptos vistos en clase
- Desarrollar habilidades prácticas
- Preparar para proyectos profesionales futuros

## 🔑 Conceptos Clave

### Git
Sistema de control de versiones que permite:
- Rastrear cambios en archivos
- Colaborar con otros
- Revertir cambios si es necesario
- Mantener historial del proyecto

### GitHub
Plataforma de hosting para proyectos Git que ofrece:
- Almacenamiento remoto
- Herramientas de colaboración
- Control de issues y proyectos
- Integración continua

### Markdown
Lenguaje de marcado ligero usado para:
- Escribir documentación
- Formatear texto de manera simple
- Crear archivos README
- Documentar proyectos

### Taller Académico
Actividad práctica educativa para:
- Aplicar teoría en práctica
- Desarrollar habilidades
- Evaluar competencias
- Preparar para proyectos reales

## 📈 Criterios de Evaluación

Este proyecto será evaluado en:

1. **Funcionalidad** (40%)
   - ¿El código funciona correctamente?
   - ¿Cumple con los requisitos?

2. **Calidad del Código** (25%)
   - ¿Es legible y mantenible?
   - ¿Sigue buenas prácticas?

3. **Documentación** (20%)
   - ¿Está completa y clara?
   - ¿Es profesional?

4. **Control de Versiones** (15%)
   - ¿Uso apropiado de Git?
   - ¿Commits descriptivos?
